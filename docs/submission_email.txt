   - Surfaces lightweight diff summaries via GET /nodes/{node_id}/changes.

3. Version-Pinned Selections & Defensive LLM Generation:

   - Implements an idempotency policy using selection content hash fingerprints.
   - Provides a deterministic local fallback labeled explicitly when unconfigured or offline.

4. Queryable Staleness Detection:
   - The retrieval API (GET /generations) dynamically evaluates source node traceability against the latest ingested version, flagging changed nodes as "stale" with old vs current hashes, while keeping unchanged nodes "current".

5. Verification & Tests:
   - Includes 20 automated tests in pytest covering parser edge cases, versioning diffs, Pydantic validation, selection immutability, and end-to-end API workflows.
